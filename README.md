# Shania Azahra – Portfolio Website

Static site (HTML + CSS + JS), no build step.

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy
Netlify: connect the GitHub repo (build command empty, publish directory `.`) or drag the folder into app.netlify.com/drop.
